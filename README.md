# Bishrav Shiwakoti — Portfolio

Personal portfolio for Bishrav Shiwakoti, a Backend & AI Systems Engineer focused on backend systems, distributed systems, AI/ML infrastructure, real-time platforms, search/retrieval, developer tooling, and production engineering.

## Run locally

```bash
npm ci
npm run dev
```

Build and preview the production bundle:

```bash
npm run build
npm run preview
```
